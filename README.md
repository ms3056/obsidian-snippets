# Obsidian CSS Snippets

Custom CSS snippets for Michael's Obsidian vaults (main vault `/Users/hiromike/Documents/Development` and Writing vault `/Users/hiromike/Documents/Writing`).

> **How snippets work:** Obsidian loads any enabled `.css` file from `<vault>/.obsidian/snippets/`. BRAT cannot install snippets (plugins only), so to use these: copy the `.css` files into your vault's snippets folder and enable them under **Settings → Appearance → CSS snippets**.

## Current snippets

| File | Purpose |
|---|---|
| `accent-styles.css` | Accent color styling helpers |
| `active-file-highlight.css` | Highlight the active file in the file explorer |
| `auto-hide.css` | Auto-hide the sidebars (used by Explorer Category Tabs plugin integration) |
| `card_layout.css` | Card-style note layouts |
| `compact-tasks.css` | Compact Tasks plugin rendering |
| `hide-scrollbars.css` | Hide scrollbars for a cleaner UI |
| `rainbow-headings.css` | Rainbow-colored headings |
| `sidebar-tabs.css` | Sidebar tab styling |
| `table-styling.css` | Table styling improvements |
| `top-tabs.css` | Top tabs styling |
| `ui-colors.css` | UI color tweaks (dark theme palette) |
